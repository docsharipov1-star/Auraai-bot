# Подключение Google Sheets к боту

## 1. Создай сервисный аккаунт

1. Перейди на https://console.cloud.google.com
2. Создай новый проект (или выбери существующий)
3. Включи API:
   - Google Sheets API
   - Google Drive API
4. Перейди в **IAM & Admin → Service Accounts**
5. Нажми **Create Service Account**
   - Имя: `auraai-clinic`
6. На шаге 3 — пропусти, нажми **Done**
7. Открой созданный аккаунт → **Keys → Add Key → Create new key → JSON**
8. Скачается файл вида `auraai-clinic-XXXXXX.json`

## 2. Дай доступ к таблицам

Открой каждую из трёх таблиц в браузере и нажми **Поделиться**:
- Добавь email сервисного аккаунта (вида `auraai-clinic@project-id.iam.gserviceaccount.com`)
- Роль: **Читатель (Viewer)**

Таблицы:
- Основная клиника
- Мутолиб
- МИС/Звонки

## 3. Добавь в Railway

1. Открой файл JSON сервисного аккаунта
2. Скопируй всё содержимое (это будет одна строка после минификации)
3. В Railway Dashboard → твой проект → **Variables**
4. Добавь переменную:
   - Ключ: `GOOGLE_CREDS_JSON`
   - Значение: вставь JSON полностью (как строку)

## 4. Установи библиотеки

В Railway они установятся автоматически при наличии в requirements.txt.
Добавь в requirements.txt:
```
gspread>=6.0.0
google-auth>=2.28.0
```

## 5. Проверь в боте

Отправь в Telegram-бот:
```
/report
```

Должен прийти недельный отчёт с данными по врачам и первичным пациентам.

## Доступные команды

| Команда | Описание |
|---------|----------|
| `/report` | Полный отчёт за 7 дней + AI рекомендации |
| `/today` | Данные за сегодня |
| `/doctor Кристина` | Детальный отчёт по врачу |
| `/patients` | Воронка первичных пациентов |
