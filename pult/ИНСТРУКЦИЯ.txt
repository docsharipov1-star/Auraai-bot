ПУЛЬТ КЛИНИКИ «АУРА» — УСТАНОВКА НА СЕРВЕР TIMEWEB
====================================================

ШАГ 1. Ящик для отправки кодов (5 минут)
  1. Заведи отдельный ящик на Mail.ru, например pult-aura@mail.ru
     (можно и свой, но отдельный удобнее).
  2. В этом ящике: Настройки → Безопасность → «Пароли для внешних приложений»
     → «Добавить» → назови «Пульт» → доступ «Полный доступ к Почте (IMAP, SMTP)».
  3. Скопируй пароль, который покажет Mail.ru. Это НЕ пароль от ящика.

ШАГ 2. Найти сервер
  1. Зайди на timeweb.cloud → «Облачные серверы» → сервер с IP 92.53.124.13.
  2. Там же видно root-пароль (или кнопка «Сбросить пароль»).

ШАГ 3. Закачать папку pult на сервер
  Нужна программа FileZilla (бесплатная, filezilla-project.org) или WinSCP.
    Хост:     sftp://92.53.124.13
    Логин:    root
    Пароль:   root-пароль из шага 2
    Порт:     22
  Перетащи папку «pult» целиком в папку /root на сервере.
  Должно получиться: /root/pult/setup_pult.sh, /root/pult/pult_server.py,
  /root/pult/static/index.html

ШАГ 4. Установить
  В Timeweb на странице сервера нажми «Консоль», войди как root и выполни:
      bash /root/pult/setup_pult.sh
  Скрипт спросит:
    • твою почту — с неё ты будешь входить как владелец;
    • ящик Mail.ru из шага 1;
    • пароль для внешнего приложения из шага 1.
  В конце напишет адрес пульта:  http://92.53.124.13:8600

ШАГ 5. Первый вход
  1. Открой адрес, введи свою почту → «Получить код» → код из письма → «Войти».
  2. «Настройки → Доступ администраторов» → впиши почту администратора → «Дать доступ».
  3. Администратор заходит по тому же адресу со своей почты.

ЕСЛИ ЧТО-ТО НЕ ТАК
  • Сайт не открывается: в Timeweb → «Сетевые правила/Firewall» открой порт 8600 (TCP).
  • Письмо с кодом не приходит: проверь «Спам». Посмотреть ошибки на сервере:
        journalctl -u pult -n 50 --no-pager
    Если почта не настроена, код для входа будет прямо в этих строках.
  • Поменять почту или пароль ящика: nano /opt/pult/.env  → сохранить →
        systemctl restart pult
  • Обновить пульт новой версией: закачай новую папку pult в /root и снова
        bash /root/pult/setup_pult.sh    (данные и настройки сохранятся)

ГДЕ ДАННЫЕ
  • База: /opt/pult/data/pult.db
  • Копии: /opt/pult/backups — сервер сам делает копию каждый день и хранит 30 последних.
  • Раз в неделю скачивай копию себе: «Настройки → Скачать полную копию».

ПЕРЕНОС ДАННЫХ ИЗ СТАРОГО ПУЛЬТА (claude.ai)
  В старом пульте: «Настройки → Скачать полную копию».
  В новом: «Настройки → Восстановить из файла» → выбери этот файл.

ВАЖНО ПРО БЕЗОПАСНОСТЬ
  • Сейчас пульт работает по http (без замка в браузере). Для клиники лучше подключить
    домен и https — когда будет домен (например pult.твой-сайт.ru), это делается за 10 минут.
  • Сервис vps-api на этом же сервере (порт 9090, управление сервером из бота) по умолчанию
    защищён паролем, который записан в коде бота. Установщик предупредит, если это так.
    Обязательно поменяй этот пароль — на сервере теперь данные пациентов.
